tabgroup

Opens tabs straight into named tab groups. A group is created the first time a tab asks for it.

Choosing a group from the address

Any page whose address ends with #tabgroup=<name> joins that group, for example file:///notes/week1.html#tabgroup=Work%20Notes&tabcolor=green. The tabgroup command adds this for you.

Folder rules

For local pages (file:// and localhost) opened without a #tabgroup tag: if the address contains any of the listed text, the tab joins that group. Separate several matches with commas. The first matching rule wins.
